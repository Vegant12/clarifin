## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PDF content → Gemini prompt | Malicious PDF text could attempt to override system instructions (prompt injection) |
| Gemini response → Supabase | Untrusted model output crosses into structured storage (validated by Zod) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-6-01 | Tampering / Elevation of Privilege | `buildExplanationPrompt` — prompt injection via PDF content attempting to override the no-recommendation rule | mitigate | DISCLAIM-02 clause is hard-coded as plain text at the TOP of `EXPLAIN_SYSTEM_PROMPT` before any PDF content is attached. PDF is passed to Gemini as a binary file part (`createPartFromUri`), NOT interpolated into the prompt string — PDF tokens cannot rewrite system instructions. Verified by Wave 0 test: prompt always contains "Do NOT make buy/sell recommendations". |
| T-6-05 | Tampering | Zod schema accepts arbitrary string content as section values | accept | Section strings are display-only in Phase 7 — no code execution path. `[p.N]` markers are parsed as text, not executed. ASVS V5 input validation satisfied by Zod schema rejecting non-string types. Free-form prose inside section strings is the intentional product behavior. |
</threat_model>
