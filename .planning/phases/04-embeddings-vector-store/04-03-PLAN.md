    - Load document: **`status`** must be **`'embedding'`**; if not **`embedding`**, return **`{ done: true }`** (no-op)
    - Select batch: **`from('chunks').select('id, content, chunk_index').eq('doc_id', docId).is('embedding', null).order('chunk_index', { ascending: true }).limit(MAX_CHUNKS_PER_RUN)`** where **`MAX_CHUNKS_PER_RUN`** is tuned (start **64** or **128**) to fit **~52s**
    - **`const deadline = Date.now() + MAX_EMBED_BATCH_WALL_MS`**: before each DB/API chunk, if **`Date.now() > deadline`**, break and return **`{ done: false }`** (more work remains)
    - Call **`embedTextBatch`** with **`rows.map((c) => c.content)`** only — **D4-02**; import **`import { embedTextBatch } from "@/lib/embed/gemini-embed"`**
    - For each **`chunk.id`**, **`update({ embedding: v })`** where **`v`** is Supabase-compatible **vector** payload (use **`pgvector` string** `'['+join+']'` **or** documented array format per Supabase-js **+** column type)
    - If embed throws after retries (from helper): **`failDocumentEmbed(docId, userSafeMessage)`** — **`update`** **`documents`** **`status: 'failed'`**, **`error_message`**, **`failed_at`**; **do not** **`delete`** chunks (unlike parse); **do not** set **`analyzing`** — **D4-04**
    - After updates in a round: re-query **`count`** of null embeddings for **`doc_id`**; if **0**, **`update`** **`documents`** **`status: 'analyzing'`**, return **`{ done: true }`**
    - **D4-07**: **never** write random/dummy vectors; **never** branch on **`STUB_PIPELINE_TICK`** here (stub is status API only)
    - **`grep -n "STUB_PIPELINE" src/lib/ingest/embed-document-batch.ts`** → **no** results preferred; if doc comment only, acceptable
  </acceptance_criteria>
