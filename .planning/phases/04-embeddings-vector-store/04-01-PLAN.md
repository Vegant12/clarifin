  <acceptance_criteria>
    - New file `supabase/migrations/20260508120000_phase4_hnsw_match_document_chunks.sql`
    - **`CREATE INDEX IF NOT EXISTS chunks_embedding_hnsw_idx ON public.chunks USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64)`** (no `CONCURRENTLY` — migration runs in transaction)
    - **WHERE embedding IS NOT NULL** partial index **or** index on column only rows with embedding; if partial: `CREATE INDEX ... ON public.chunks USING hnsw (embedding vector_cosine_ops) WHERE embedding IS NOT NULL` (planner-pick: use partial index to avoid empty-vector rows in index — document in SQL comment)
    - **`CREATE OR REPLACE FUNCTION public.match_document_chunks(p_doc_id uuid, p_query_embedding vector(768), p_match_count integer DEFAULT 5)`** returns **`SETOF`** or **`TABLE`** with columns: **`id uuid`**, **`content text`**, **`page_number integer`**, **`source_page_start integer`**, **`source_page_end integer`**, **`section text`**, **`chunk_type public.chunk_type_enum`**, **`distance double precision`** (cosine **`<=>`**)
    - Body: **`FROM public.chunks c WHERE c.doc_id = p_doc_id AND c.embedding IS NOT NULL`** **`ORDER BY c.embedding <=> p_query_embedding`** **`LIMIT greatest(1, least(p_match_count, 50))`** (cap match_count server-side)
    - **`STABLE`** or **`IMMUTABLE`** as appropriate; **`LANGUAGE sql`** or **`plpgsql`**; set **`search_path = public`** if **`SECURITY DEFINER`**
    - **`REVOKE ALL ON FUNCTION public.match_document_chunks(uuid, vector, integer) FROM PUBLIC`**
    - **`REVOKE ALL ON FUNCTION public.match_document_chunks(uuid, vector, integer) FROM anon, authenticated`**
    - **`GRANT EXECUTE ON FUNCTION public.match_document_chunks(uuid, vector, integer) TO service_role`**
    - Comment in SQL: **`ANALYZE public.chunks;`** after large backfills (operational; optional **`ANALYZE`** at end of migration for dev freshness)
    - `grep -n match_document_chunks supabase/migrations/20260508120000_phase4_hnsw_match_document_chunks.sql` returns hits
  </acceptance_criteria>
  <action>
    1. Add migration with idempotent-safe statements (`IF NOT EXISTS` for index where supported).
    2. Implement **D4-06** filter **strictly** on **`p_doc_id`** — no optional doc id, no dynamic SQL.
    3. Use **cosine distance** operator **`<=>`** per **D4-05** / **D4-06**.
    4. Document function signature in migration header comment for Phase 10 RAG consumers.
  </action>
