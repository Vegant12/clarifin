## Spacing Scale

Uses the project-wide 8-point scale already in use across Phase 7–8 components.
All values are Tailwind class equivalents.

| Token | px Value | Tailwind Class | Usage in Phase 9 |
|-------|----------|----------------|-------------------|
| xs | 4px | gap-1, p-1 | Icon-to-label gaps inside ticker badge |
| sm | 8px | gap-2, p-2 | Metric label-to-value vertical spacing in 2×2 grid |
| grid-cell | 12px | px-3 | 2×2 metric grid cell horizontal padding — tighter than md (16px) to fit two columns without crowding the metric values, larger than sm (8px) for comfortable reading. Used only on grid cells (not as a general layout token). |
| md | 16px | gap-4, p-4 | Card internal padding (stock widget and chart card) |
| lg | 24px | gap-6, px-6 | ExplanationPanel column gap between stock widget and chart |
| xl | 32px | gap-8 | Gap between chart card and first explanation section |
| 2xl | 48px | — | Existing ExplanationPanel inter-section gap (unchanged) |

Exceptions:
- **Chart Y-axis tick labels** use 12px font (Recharts default tick size); this is a
  charting-library internal measurement, not a layout spacing value.
- **`gap-px` (1px) on the 2×2 grid container** (`grid gap-px bg-border`) is a hairline
  visual-border simulation technique, not a layout spacing value. The 1px gap is filled
  by the `bg-border` on the container, which shows through between the white `bg-card`
  cells, producing a divider line. It is excluded from the spacing scale table because
  it serves a visual-border purpose, not a layout-spacing purpose.

## Typography

Inherits project-wide type scale from globals.css. Phase 9 uses a subset.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (text-base) | 400 (regular) | 1.5 | Fallback / unavailable text |
| Label | 14px (text-sm) | 400 (regular) | 1.4 | Metric labels inside 2×2 grid, timestamp, axis labels |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Chart card title ("Financial Trend") |
| Display | — | — | — | Not used in Phase 9 |

Additional Phase 9-specific type decisions:

- **Ticker badge text:** 12px (text-xs), weight 600 (semibold), all-caps. Renders inside
  a small pill badge at the stock widget header.
- **Metric value:** 20px (text-xl), weight 600 (semibold). The four numeric values in the
  2×2 grid (price, P/E, P/B, dividend yield) must be visually dominant over their labels.
- **IDX label:** 12px (text-xs), weight 400 (regular), `text-muted-foreground`. Rendered
  adjacent to the ticker badge.
- **"as of…" timestamp:** 12px (text-xs), weight 400, `text-muted-foreground`. Renders in
  the stock widget header row, trailing after the IDX label.
- **Chart axis tick labels:** 12px, weight 400, `text-muted-foreground` (Recharts `tick`
  prop with `fontSize={12}`).
- **Chart legend text:** 12px, weight 400, `text-foreground`.
- **Chart tooltip values:** 14px (text-sm), weight 600, `text-foreground`.
- **Unavailable fallback text:** 14px (text-sm), weight 400, `text-muted-foreground`.
  Single sentence, no heading above it.

## Color

Project-wide tokens from globals.css. Phase 9 adds no new color tokens.

| Role | OKLCH Value | Hex approx | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | oklch(1 0 0) | #ffffff | ExplanationPanel bg, card bg |
| Secondary (30%) | oklch(0.96 0 0) | #f4f4f5 | Muted/skeleton pulse bg (`bg-muted`) |
| Accent / primary (10%) | oklch(0.59 0.16 156) | ~#10b981 (emerald-600) | Revenue bars, focus rings, ticker badge bg |
| Border | oklch(0.92 0 0) | ~#e4e4e7 (zinc-200) | Card borders, grid dividers |
| Muted foreground | oklch(0.45 0 0) | ~#71717a (zinc-500) | Timestamp, IDX label, axis ticks, unavailable text |
| Destructive | oklch(0.58 0.22 27) | ~#dc2626 (red-600) | Not used in Phase 9 |

Accent (emerald-600) is reserved specifically for:
1. Revenue bars in the ComposedChart (`fill="var(--color-primary)"`)
2. Ticker badge background in the stock widget header
3. Focus rings on any interactive chart tooltip elements

Net Income bars use `fill="var(--color-secondary)"` (zinc-100) with
`stroke="var(--color-border)"` to visually differentiate from Revenue bars while
remaining in the project's neutral palette.

Net Margin line uses `stroke="var(--color-muted-foreground)"` — a dashed or dotted
stroke (Recharts `strokeDasharray="4 2"`) to distinguish it from the bars at a glance.

## Component Inventory

All components are shadcn official — no third-party registry additions in this phase.

> **Visual Hierarchy note:** Primary visual anchor in the stock widget is the four metric
> values rendered at text-xl/600 (price, P/E, P/B, dividend yield) — they are the
> largest, heaviest elements in that card and draw the eye first. Primary visual anchor
> in the trend card is the ComposedChart bar area (Revenue + Net Income bars at full
> card width), which occupies the majority of the card's vertical space.

### StockWidget (new — `src/components/doc/stock-widget.tsx`)

Container: shadcn `Card` with `p-4 gap-3` (override default `gap-6 py-6` via className).

**Header row** (single flex row, `items-center gap-2`):
- Ticker badge: `<span>` with `bg-primary text-primary-foreground text-xs font-semibold
  px-2 py-1 rounded-full uppercase` — e.g., "BBCA"
- IDX label: `<span class="text-xs text-muted-foreground">IDX</span>`
- Timestamp: `<span class="text-xs text-muted-foreground ml-auto">as of {date}</span>`
  — right-aligned via `ml-auto`

**Body: 2×2 metric grid** (`grid grid-cols-2 gap-px bg-border` with each cell
`bg-card px-3 py-2`):

| Grid position | Label | Format example |
|---------------|-------|----------------|
| top-left | Price | Rp 9.275 |
| top-right | P/E | 12.4× |
| bottom-left | P/B | 1.8× |
| bottom-right | Div. Yield | 3.2% |

Each grid cell layout: `flex flex-col gap-1`. Label: `text-xs text-muted-foreground`.
Value: `text-xl font-semibold text-foreground`.

Grid border pattern: `grid gap-px bg-border` creates 1px hairline dividers between
cells without explicit border classes on individual cells — `gap-px` is a visual-border
technique (see Spacing Scale Exceptions). Outer card `border border-border rounded-lg
overflow-hidden` clips the grid edges cleanly.

### TrendChartCard (new — `src/components/doc/trend-chart-card.tsx`)

Container: shadcn `Card` styled to match ScoreCard — `rounded-lg border border-border
bg-background p-4 flex flex-col gap-4` (mirrors ScoreCard exactly).

**Card header:**
- Title: `<h3 class="text-xl font-semibold text-foreground">Financial Trend</h3>`
  followed by `<span class="text-xs text-muted-foreground">({ticker} · {startYear}–{endYear})</span>`

**Chart area:** Recharts `ComposedChart` with `ResponsiveContainer width="100%" height={220}`.

Chart anatomy:
- `CartesianGrid` with `strokeDasharray="3 3"` and `stroke="var(--color-border)"`
- `XAxis` keyed to the year string; `tick={{ fontSize: 12, fill: "var(--color-muted-foreground)" }}`
- Left `YAxis` (primary): Revenue + Net Income bars, formatted with `formatIDR()`; same
  tick styling as XAxis
- Right `YAxis` (secondary, `yAxisId="margin"`): Net Margin percentage 0–100, suffix "%";
  `tickFormatter={(v) => \`${v}%\``}
- `Bar` for Revenue: `dataKey="revenue"` `fill="var(--color-primary)"` `yAxisId="left"
  `radius={[4, 4, 0, 0]}`
- `Bar` for Net Income: `dataKey="netIncome"` `fill="var(--color-secondary)"
  `stroke="var(--color-border)"` `strokeWidth={1}` `yAxisId="left"` `radius={[4, 4, 0, 0]}`
- `Line` for Net Margin: `dataKey="netMarginPct"` `stroke="var(--color-muted-foreground)"
  `strokeDasharray="4 2"` `dot={false}` `yAxisId="margin"`
- `Tooltip` with custom formatter using `formatIDR()` for bar values and `"{v}%"` for margin
- `Legend` with `verticalAlign="bottom"` `height={28}` using default Recharts legend renderer

**No chart data state:** Component is not rendered at all (parent null-guards on `chartData`
being null or empty array). No empty card is shown.

### StockLoadingSkeleton (new — `src/components/doc/stock-loading-skeleton.tsx`)

Follows the `PdfLoadingSkeleton` pattern exactly: `role="status"`, `aria-busy="true"`,
`aria-label="Loading market data…"`.

Stock widget skeleton: one `animate-pulse rounded-lg bg-muted` block at `h-[108px] w-full`
— approximates the compact card height.

Trend chart skeleton: one `animate-pulse rounded-lg bg-muted` block at `h-[268px] w-full`
— approximates chart card height (220px chart + 48px header).

Both skeletons render in sequence inside the `ExplanationPanel` slot, stacked with `gap-6`.

### ExplanationPanel extension

Props added: `ticker: string | null`, `stockData: StockData | null`,
`chartData: ChartDataPoint[] | null | undefined`, `stockError: boolean`.

Column rendering order (unchanged from D-08):
1. ScoreCard (Phase 8, existing)
2. StockWidget slot — conditional on `ticker !== null`
   - If `stockData` is loading: `<StockLoadingSkeleton />` (widget placeholder only)
   - If `stockError === true`: inline muted fallback (see Copywriting Contract)
   - If `stockData` available: `<StockWidget data={stockData} ticker={ticker} />`
3. TrendChartCard slot — conditional on `chartData` having ≥1 entry
   - If chart data is loading (stock fetch in progress): `<StockLoadingSkeleton />` (chart placeholder)
   - If `chartData` null or empty: render nothing
   - If `chartData` available: `<TrendChartCard data={chartData} ticker={ticker} />`
4. Explanation sections (existing SECTION_ORDER map, unchanged)

## IDR Formatting Contract

Utility: `formatIDR(amount: number): string` — added to `src/lib/utils.ts` (or
`src/lib/format/idr.ts` if the planner prefers a dedicated file).

| Threshold | Output format | Example input | Example output |
|-----------|--------------|---------------|----------------|
| ≥ 1,000,000,000,000 | "Rp X.XX triliun" | 85_000_000_000_000 | "Rp 85.00 triliun" |
| ≥ 1,000,000,000 | "Rp X.XX miliar" | 1_250_000_000 | "Rp 1.25 miliar" |
| ≥ 1,000,000 | "Rp X.XX juta" | 500_000_000 | "Rp 500.00 juta" |
| < 1,000,000 | "Rp X,XXX" (comma-sep) | 9275 | "Rp 9,275" |

Applied to:
- Stock price (left Y-axis tick labels and tooltip value)
- Revenue bar tooltip value
- Net Income bar tooltip value
- Left Y-axis tick labels (abbreviated: "Rp 85T" or "Rp 1.2M" short form for axis;
  full form in tooltip only — keeps axis readable)

Axis short-form rules (separate from `formatIDR` — a `formatIDRShort` variant):
- ≥ 1T → "Rp {X}T" (e.g., "Rp 85T")
- ≥ 1B → "Rp {X}M" (using "M" = miliar for brevity on axis)
- ≥ 1M → "Rp {X}Jt"

## Loading States

| Component | Loading state | Fallback (no data) |
|-----------|---------------|-------------------|
| StockWidget | `<StockLoadingSkeleton />` (h-108px pulse block) | Muted inline text (see Copywriting Contract) |
| TrendChartCard | `<StockLoadingSkeleton />` (h-268px pulse block) | Not rendered at all — null guard |
| Both (ticker null) | Neither component rendered | Neither component rendered |

Loading is triggered while the `GET /api/stock/[ticker]` response is in-flight (SWR /
fetch from the RSC page or client fetch hook — planner decides). Both skeletons display
simultaneously during the single fetch.

## Interaction States

### Stock widget grid cells

Static — no hover, click, or focus states needed. Metrics are read-only data.

### Chart tooltip

Recharts default pointer-tracking tooltip. No custom interaction beyond Recharts built-in
hover. Tooltip appears on mouse enter of the chart area.

Custom tooltip content: show year as header, then three rows:
- "Revenue: Rp X.XX triliun"
- "Net Income: Rp X.XX miliar"
- "Net Margin: X.X%"

Tooltip container: `bg-background border border-border rounded-md px-3 py-2 shadow-sm
text-sm` — matches site card aesthetic.

### Responsive behavior

- ExplanationPanel column is already constrained within the split-pane layout (Phase 7).
  No new layout changes.
- StockWidget 2×2 grid: fixed two-column layout. Does not reflow to single column.
  Min-width: stock widget never renders below 280px container width (split pane already
  enforces this on desktop).
- TrendChartCard: `ResponsiveContainer width="100%"` adapts automatically. Chart is
  readable at 280px+ width (minimum 3 bars visible).
- Mobile (≤768px): explanation and PDF viewer tab-switch (VIEWER-04, Phase 7 existing).
  Stock widget and chart render in the explanation tab — same vertical stack as desktop.
