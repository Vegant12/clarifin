<objective>
Deliver the three reliability protections that keep Clarifin within free-tier limits and prevent the Supabase project from pausing:

1. **INFRA-03 — Concurrency cap:** Before any Gemini call in `analyze-document-batch.ts`, query the count of documents in `status="analyzing"`. If more than 2 are active, return `{ done: false }` so the cron re-picks this doc on the next tick.
2. **INFRA-04 — PDF cleanup:** After `embed-document-batch.ts` confirms all chunks have non-null embeddings in pgvector, remove the raw PDF from the `pdfs` Storage bucket. On partial failure, preserve the PDF for retry.
3. **INFRA-05 — Keep-alive cron:** New `GET /api/cron/keep-alive` route runs `SELECT id FROM documents LIMIT 1` once weekly via Vercel Cron, preventing Supabase Feb-2026 inactivity pause.

Purpose: Without these protections, burst traffic will exhaust the Gemini quota (cascade failure), orphan PDF files will accumulate (UU PDP + egress cost), and the database will pause after 7 idle days. Phase 12 launch depends on this.
Output: One modified service module (concurrency cap), one modified service module (PDF cleanup), one new cron route, one new cron schedule entry, three test files.
</objective>

import { supabaseAdmin } from "@/db/client";

export const runtime = "nodejs";
export const maxDuration = 10;

/**
 * INFRA-05: Weekly Vercel Cron keep-alive.
 *
 * Runs a trivial `SELECT id FROM documents LIMIT 1` against Supabase to
 * prevent the project from pausing after 1 week of inactivity (Supabase
 * Feb 2026 policy).
 *
 * Scheduled in vercel.json at `0 0 * * 0` (Sunday 00:00 UTC, weekly).
 * Public route — no auth gate in v1 (the query is read-only and trivial).
 */
export async function GET(): Promise<Response> {
  try {
    const { error } = await supabaseAdmin
      .from("documents")
      .select("id")
      .limit(1);

    if (error) {
      return NextResponse.json(
        { ok: false, error: error.message },
        { status: 500 },
      );
    }
    return NextResponse.json({ ok: true });
  } catch (err) {
    return NextResponse.json(
      { ok: false, error: String(err) },
      { status: 500 },
    );
  }
}
