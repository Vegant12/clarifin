## Spacing Scale

Declared values (must be multiples of 4, matching Tailwind v4 default scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip inner padding, inline gaps between badge labels |
| sm | 8px | Stack gap within compact card rows, button group inner gaps |
| md | 16px | Default element spacing, Card padding (px-4), chart container padding |
| lg | 24px | Section padding between chart panel and indicator strip, Card gap-6 default |
| xl | 32px | Page horizontal gutters at ≥1024px, top-of-page header clearance |
| 2xl | 48px | Major section breaks (chart zone vs search header) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Chart subpanel height (volume: 80px, RSI: 100px, MACD: 120px) — pixel-absolute because lightweight-charts requires explicit panel heights.
- Touch targets for range selector buttons: minimum 36px height on desktop (Button size `sm` — 28px — padded to 36px via py-1.5 override if needed). Not a concern on mobile (mobile shows info card only).
- SiteHeader height: 48px (h-12), consistent with Tailwind sizing convention.

## Typography

All sizes and weights are inherited from the v1.0 design system already in `globals.css` and component defaults. No new type scale is introduced.

| Role | Size | Weight | Line Height | Usage in Phase 13 |
|------|------|--------|-------------|-------------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Indicator snapshot strip one-liners, search results, autocomplete items, error state body text |
| Label | 12px (text-xs) | 400 (regular) | 1.4 | Chart axis tick labels, subpanel axis values, range selector button text, badge text |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Page heading "BBCA — Bank Central Asia" on `/ta/{ticker}` page |

Weight scale for this phase: exactly 2 weights — 400 (regular) and 600 (semibold). No other weights are used.

Additional:
- Ticker code in page heading and autocomplete results: `font-mono` (Geist Mono), text-sm, font-semibold (600). This visually distinguishes codes from names at a glance.
- Indicator snapshot label prefix ("RSI:", "MACD:"): text-xs (12px), font-semibold (600), text-muted-foreground. The plain-English description that follows: text-sm (14px), font-normal (400). This uses only the 2 declared weights.
- Display/28px is NOT used in Phase 13 — deferred to T3 probability widget (Phase 15).

## Color

Extends the v1.0 token set from `globals.css`. No new CSS custom properties are added. All references use the existing `--color-*` tokens.

| Role | Token | Hex approximation | Usage |
|------|-------|------------------|-------|
| Dominant (60%) | `--color-background` | oklch(1 0 0) ≈ #ffffff | Page background, chart container background |
| Secondary (30%) | `--color-card` / `--color-secondary` | oklch(1 0 0) / oklch(0.96 0 0) ≈ #f4f4f5 | Card backgrounds (indicator strip, search dropdown, info card on mobile), SiteHeader background (use `--color-secondary`) |
| Accent (10%) | `--color-primary` | oklch(0.59 0.16 156) ≈ #059669 (emerald-600) | Reserved-for list below |
| Destructive | `--color-destructive` | oklch(0.58 0.22 27) ≈ #dc2626 (red-600) | Invalid ticker error state only |

Accent (`--color-primary` / emerald-600) reserved for:
1. Active range selector button (1M / 3M / 6M / 1Y / 2Y) — filled emerald, white text. Inactive buttons: `variant="outline"`.
2. Bullish day volume bars in the volume subpanel — use `var(--color-primary)` (emerald).
3. Bullish candlestick bars — use `var(--color-primary)` (emerald) to match TradingView convention of green-up candles.
4. Focus ring on ticker search input — `--color-ring` (already emerald per globals.css).
5. Active nav link in SiteHeader when `NEXT_PUBLIC_TA_ENABLED=true` and the user is on `/ta/*`.

Bearish candle bars and bearish volume bars: `--color-destructive` (red-600).

EMA lines (chart overlays):
- EMA-20: `oklch(0.70 0.15 230)` ≈ blue-400 (use Tailwind `blue-400` hex `#60a5fa`).
- EMA-50: `oklch(0.75 0.12 50)` ≈ amber-400 (`#fbbf24`).
- EMA-200: `oklch(0.55 0.18 290)` ≈ violet-500 (`#8b5cf6`).
- Bollinger Bands (upper/lower): `--color-muted-foreground` (zinc-500, `#71717a`) with 40% opacity; midline: solid zinc-500.

These chart-specific color values are NOT new CSS tokens — they are hardcoded in the lightweight-charts series configuration objects in `candlestick-chart.tsx`. Use `const CHART_COLORS` object at the top of the file.

Muted text (`--color-muted-foreground`, zinc-500): axis tick labels, indicator snapshot secondary text, autocomplete result company names (ticker codes in foreground).

## Interaction Contracts

### TickerSearch

- Input placeholder: "Search IDX tickers or company names…"
- Debounce: 300ms before calling `/api/ta/search?q={query}&limit=8`.
- Dropdown max height: 320px, scrollable, `overflow-y-auto`.
- Result row: `[TICKER]` (text-sm font-mono font-semibold) + space + `Company Name` (text-sm text-muted-foreground). Height: 40px per row.
- Keyboard: arrow keys navigate, Enter selects, Escape closes.
- On select: `router.push('/ta/{TICKER}')` where TICKER is always uppercase.
- Empty query: dropdown closes, no request fired.
- No results found: show "No IDX tickers matching '{query}'" in dropdown (text-sm text-muted-foreground, py-4 px-3).
- Minimum query length before firing: 1 character.

### RangeSelector

- Exactly 5 buttons in a single row: 1M / 3M / 6M / 1Y / 2Y.
- Default selection on page load: 1Y.
- Active button: `variant="default"` (filled emerald, white label). Inactive: `variant="outline"`.
- Clicking a button updates `range` state; chart re-filters the already-loaded OHLCV data client-side (no new API call for range changes — all OHLCV loaded upfront at 2Y maximum).
- Button size: `size="sm"` (h-7).

### OverlayToggles

- 4 chip-buttons: BB / EMA-20 / EMA-50 / EMA-200.
- Default on-state: EMA-50 and EMA-200 toggled ON. BB and EMA-20 OFF.
- On-state visual: `variant="outline"` with a 3px left border in the series color (inline style `borderLeftColor`), background `bg-muted`.
- Off-state: `variant="ghost"`, no colored border.
- Toggle is purely client-side; shows/hides the corresponding lightweight-charts series via `series.applyOptions({ visible: boolean })`.

### CandlestickChart

- Rendered inside a `"use client"` wrapper component. The parent page is an RSC that passes serialized OHLCV + indicator data as props.
- Chart background: `--color-background` (white).
- Grid lines: `--color-border` (zinc-200), 1px.
- Axis text: `--color-muted-foreground` (zinc-500), Label/12px role. lightweight-charts renders canvas text and may approximate to 11px internally — do not add 11px as a separate type scale entry; keep the contract at 12px (Label).
- Crosshair: `--color-muted-foreground`, thin dashed.
- Hover tooltip: floating div with `bg-background border border-border rounded-md shadow-sm px-3 py-2 text-sm` — shows date + OHLCV values + volume. Matches v1.0 `TrendTooltip` styling.
- Candlestick up color: `var(--color-primary)` (emerald-600).
- Candlestick down color: `var(--color-destructive)` (red-600).
- Candlestick border up: emerald-700 (slightly darker for definition).
- Candlestick border down: red-700.
- Wick color matches candle body color.
- Volume bars: up day = emerald-600 at 60% opacity; down day = red-600 at 60% opacity.
- RSI line: `#3b82f6` (blue-500). Reference lines (30, 70): zinc-400 dashed.
- MACD fast line: `#6366f1` (indigo-500). MACD signal line: `#f97316` (orange-500). Histogram: emerald-600 (positive) / red-600 (negative) at 60% opacity.
- Subpanel sync: all 4 panels share a time axis via `subscribeVisibleTimeRangeChange` + `setVisibleRange` cross-calls.
- Pan/zoom: enabled by default on desktop (lightweight-charts built-in wheel + drag behavior).
- All chart-specific color values live in a `const CHART_COLORS` object at the top of `candlestick-chart.tsx` — no inline magic strings elsewhere in the file.

### IndicatorSnapshotStrip

- Scrollable horizontal row (flex-wrap on wider screens, flex-nowrap + overflow-x-auto on narrow desktop).
- Each chip: `<Card>` with `px-3 py-2`, `flex-col gap-1`, `cursor-default`. Min-width: 120px.
- Chip structure: `<p class="text-xs font-semibold text-muted-foreground">{indicatorName}</p>` + `<p class="text-sm text-foreground">{oneLineSummary}</p>`.
- On hover of chip: `<Tooltip>` opens with plain-English definition of the indicator (TA-IND-06).
- One-liner format (locked by ROADMAP success criterion #2): `"{Indicator}: {plain-English description}"`. Never raw numbers. Examples:
  - "RSI: Near oversold territory (39)"
  - "MACD: Bullish crossover yesterday"
  - "Bollinger Bands: Price near upper band — extended"
  - "EMA-50: Price trading above — short-term uptrend"
  - "EMA-200: Price below — long-term downtrend"
  - "Stochastic: In overbought zone (81/74)"
  - "OBV: Rising with price — volume confirms trend"
  - "ATR: Moderate volatility (Rp 320 / share)"

### Loading State (TAPageSkeleton)

- Displayed immediately while data fetches from `/api/ta/analysis/[ticker]`.
- Structure:
  - Skeleton block: w-full h-8 (search bar placeholder), rounded-md.
  - Gap: 16px.
  - Skeleton block: w-full h-[600px] (chart area placeholder — covers all 4 panels), rounded-xl.
  - Gap: 16px.
  - Skeleton block: w-full h-16 (indicator strip placeholder), rounded-lg.
- All skeleton blocks: `animate-pulse bg-muted rounded-md`.

### Invalid Ticker Error State (TAErrorCard)

- Shown when `/api/ta/analysis/[ticker]` returns 404 or the ticker is not found in `ticker_metadata`.
- Card centered on page, max-w-md, mx-auto, mt-16.
- Icon: `lucide-react` `<AlertCircle>` size-8, text-destructive.
- Heading: "Ticker not found" (text-xl font-semibold).
- Body: Copy specified in Copywriting section below.
- CTA: `<Button variant="outline">` linking back to search / `/ta`.

### Sparse Data State (SparseDataCard)

- Shown when ticker has <30 candles of OHLCV history.
- Card centered, max-w-md, mx-auto, mt-16.
- Icon: `lucide-react` `<BarChart2>` size-8, text-muted-foreground.
- Heading: "Insufficient price history" (text-xl font-semibold).
- Body: Copy specified in Copywriting section below.
- No chart, no indicator panels rendered.

### SiteHeader

- `<header>` element, `sticky top-0 z-50 h-12 bg-secondary border-b border-border`.
- Left: "Clarifin" wordmark in `text-sm font-semibold`, linked to `/`.
- Right: nav links.
  - "Upload Document" — `<Button variant="ghost" asChild>` wrapping `<Link href="/">`.
  - "TA Analysis" — conditionally rendered only when `NEXT_PUBLIC_TA_ENABLED === 'true'`. Uses `<Button variant="ghost" asChild>`. Active state (on `/ta/*`): underline decoration or `text-primary` color to indicate current surface.
- On `<640px`: "TA Analysis" text label is hidden; render icon only (`lucide-react` `<LineChart>` icon). Add `aria-label="TA Analysis"` to the icon-only button so screen readers announce the destination correctly.

## Accessibility

- All interactive elements have visible focus rings via `focus-visible:ring-3 focus-visible:ring-ring/50` (inherited from shadcn Button).
- `<CandlestickChart />` wrapper: `role="img"` + `aria-label="{TICKER} interactive price chart, {range} view"`.
- `<TickerSearch />`: `aria-label="Search IDX tickers"`, `aria-expanded` on open state.
- `<TAPageSkeleton />`: `role="status"` + `aria-label="Loading chart data…"` + `aria-busy="true"`.
- Indicator chip tooltips: triggered on focus as well as hover (keyboard-accessible).
- Range selector: active button gets `aria-pressed="true"`.
- Color is never the sole indicator of state — candle direction is also conveyed by the candle shape (hollow body = up, filled = down in lightweight-charts default).
- SiteHeader "TA Analysis" nav link on <640px (icon-only): add `aria-label="TA Analysis"` to the button element so screen readers announce the destination when the text label is hidden.
