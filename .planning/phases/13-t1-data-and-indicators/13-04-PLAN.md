| Browser (public) → /api/ta/analysis, /api/ta/search | Unauthenticated user input (ticker path param, search query) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-13 | Tampering | ticker path param injection | mitigate | `z.string().regex(/^[A-Z]{1,5}$/)` safeParse at route entry before any DB/compute; 400 on failure. |
| T-13-14 | Tampering | PostgREST filter injection via search `q` | mitigate | Sanitize `q` to alphanumeric+space before interpolating into `.or()` filter string; max length 20; Zod-validated. |
| T-13-15 | Denial of Service | unbounded result/row reads | mitigate | analysis limited to 520 bars; search `.limit(<=20)`. No rate limiting yet (TA-INFRA-01 is Phase 16) — accepted for T1 (NEXT_PUBLIC_TA_ENABLED=false in prod gates exposure). |
| T-13-16 | Information Disclosure | DB errors leaked to client | mitigate | Search fails open with `{ results: [] }`; analysis returns generic error strings, never raw error objects. |
