## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| yahoo-finance2 (unofficial scraper) → seed script | Untrusted external market data crosses into our DB |
| seed script (service_role) → ohlcv_cache / ticker_metadata | Privileged bulk writes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05 | Tampering | corrupt/garbage OHLCV from yahoo | mitigate | Four-rule bar validation (high<low, close<=0, volume<0, >50% single-bar return) rejects bad bars before upsert; cross-check 5 bars vs TradingView. |
| T-13-06 | Denial of Service | yahoo rate-limiting mid-backfill | mitigate | withBackoff (500/1000/2000ms) on rate-limit errors; per-ticker log-and-continue so one failure doesn't abort the run (D-06). |
| T-13-07 | Tampering | duplicate rows on re-run | mitigate | Upserts use `onConflict: "ticker,date"` and `onConflict: "ticker"`; re-running is idempotent. |
| T-13-08 | Information Disclosure | service-role key in script | accept | Key read from env (`requireEnv`), never committed; script is run manually with env set. Standard for one-shot ops scripts (matches smoke-vector-perf.ts). |
</threat_model>
